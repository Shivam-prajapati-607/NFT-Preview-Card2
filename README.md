# NFT Preview Card Component

This is my solution to the NFT Preview Card Component challenge from Frontend Mentor.

## Overview

The project displays an NFT preview card with:
- NFT image
- Title and description
- Ethereum value
- Time remaining
- Creator information

## Built With

- HTML5
- CSS3
- Flexbox

## Features

- Clean and modern card design
- Responsive layout
- Semantic HTML structure
- Custom styling with CSS
